# News in One Image — 23 November 2026

A small Python program that sums up the world's news of Monday 23 November 2026
in a single image: a 1024x1024 newspaper front page drawn entirely with code.

Run it:

    python3 main.py

It writes `entry.png` (1024x1024) next to the script. No network access, no
randomness — every run produces byte-identical output.

Headlines are drawn from that day's reporting: COP31 closing in Antalya with
no deal as the lead story, the US midterms, the loss of the Russian corvette
Merkury, strikes near Kyiv, the Shenzhen three-way meeting, the Banten factory
fire, the Nikkei's slide, and the day's football.

Entry for the make.fun bounty "Sum up 23 November's world news in one image"
(news-image-20261123). MIT licensed.
